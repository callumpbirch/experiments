# experiments

A general-purpose sandbox for trying out code ideas, scripts, and small experiments.

## Prerequisites

- [Git](https://git-scm.com/) for cloning and version control
- A language runtime appropriate for your experiment (e.g. Python, Node.js, etc.)

## Getting Started

Clone the repository and navigate into it:

```bash
git clone <repo-url>
cd experiments
```

## Usage

### Adding a new experiment

1. Create a new directory for your experiment:
   ```bash
   mkdir my-experiment
   cd my-experiment
   ```
2. Add your code files inside that directory.
3. Include a brief comment or small `README` in the directory explaining what the experiment does.

### Running an experiment

Navigate into the experiment's directory and run it with the appropriate command for the language used. For example:

```bash
# Python
python script.py

# Node.js
node script.js

# Shell
bash script.sh
```

## Contributing

1. Create a new branch for your experiment: `git checkout -b my-experiment`
2. Add your experiment in its own directory.
3. Commit your changes with a descriptive message.
4. Open a pull request describing what you experimented with and what you found.
